# PRD — eduApp v1 (시범 운영)

> 기준: [설계 문서](superpowers/specs/2026-11-06-eduapp-design.md) · 용어: [도메인 정의서](01-domain-definition.md) · 2026-11-06

## 1. 문제

학부모는 아이 수준에 맞는 체험 프로그램을 찾으려고 **기관 홈페이지를 하나씩** 뒤진다. 찾아도 신청 시작이나 마감을 놓치고, 아이가 배우는 내용과 맞는지 판단하기 어렵다.

## 2. 목표와 성공 기준

| 목표 | 성공 기준 (시범 운영 4주) |
|---|---|
| 흩어진 프로그램을 한곳에서 | 핵심 기관 10곳 이상, 진행 중/예정 프로그램 매일 갱신 |
| 신청 시기를 놓치지 않게 | 관심 프로그램 알림이 신청 시작 1일 전·1시간 전에 도착 |
| 배우는 내용과 연결 | 노출 프로그램의 80% 이상에 연결 단원과 이유 표시 |
| 매주 다시 여는 앱 | 시범 사용자의 50% 이상이 주 2회 이상 접속 |

## 3. 대상

- **학부모**(서울·경기 초등 자녀). 지인 대상 시범 운영.
- 비대상(v1): 선생님, 유아·중·고, 다른 지역.

## 4. 기능 요구사항

| ID | 기능 | 우선순위 | 요구사항 |
|---|---|---|---|
| F1 | 로그인 | 필수 | 이메일 또는 소셜 로그인. 로그인 없이 사용 불가 |
| F2 | 자녀 등록 | 필수 | 별명, 학교(이름 검색), 학년. 여러 명. 수정·삭제 가능 |
| F3 | 관심 지역 | 필수 | 서울·경기 시군구 복수 선택 |
| F4 | 체험 목록 | 필수 | 관심 지역의 진행 중/예정 프로그램. 필터: 자녀(학년), 날짜, **우리 학교 쉬는 날** |
| F5 | 체험 상세 | 필수 | 기관, 기간, 대상, 신청 기간, 비용, **연결 단원 + 이유**, **가기 전에 읽어요(책 + 이유)**, 기관 페이지 바로가기 |
| F6 | 관심 표시와 알림 | 필수 | 관심 표시 → 신청 시작 1일 전·1시간 전, 마감 임박 알림. 시작 시각이 없으면 기간만 안내 |
| F7 | 우리 학교 교과 | 필수 | 자녀 학교·학년의 교과별 교과서(출판사). "확인 중" 표시. 학부모가 출판사 수정 가능 |
| F8 | 교과서 준비 알림 | 필수 | 학교 수집이 끝나면 "교과서 정보가 준비됐어요" 알림 |
| F9 | 예상 진도 | 필수 | 이번 주 예상 학습 단원(성취기준). "예상" 표시 |
| F10 | 책·활동 추천 | 필수 | 예상 진도에 맞는 책 |
| F11 | 오늘의 질문 | 필수 | 하루 1개 질문 + 생각 힌트 (힌트는 눌러서 펼침) |
| F12 | 집 미니 실험 | 필수 | 재료, 순서, 안전 메모. 승인된 것만 |
| F13 | 운영자 승인 | 필수 | 운영자만: 승인 대기 실험 목록 → 승인/거절 |

## 5. 비기능 요구사항

- **정확성**: 확인 안 된 교과서는 "확인 중". 마감 프로그램은 노출하지 않음.
- **안전**: 불·칼·화학약품 실험 금지. 운영자 승인 필수.
- **개인정보**: 자녀 정보는 본인만 조회(RLS). 자녀 실명 대신 별명.
- **신선도**: 프로그램은 매일 1회 갱신. 교과서는 자녀 등록 다음 날까지.
- **비용**: AI 처리는 Claude 예약 작업(구독 사용량). 별도 API 비용 없음.
- **플랫폼**: Android 우선(Flutter). iOS는 같은 코드로 이후.

## 6. 범위 밖 (v1)

선생님 기능, 앱 내 신청·결제, 실시간 AI 생성, 체험 후 기록, 방학 계획표, 공개 출시.

## 7. 위험과 대응

| 위험 | 대응 |
|---|---|
| 기관 홈페이지 구조 변경으로 수집 실패 | 기관별 수집기 분리, 실패 기록 후 다음 날 수정 |
| 학교 공지에서 교과서를 못 찾음 | "공지 없음" 상태 + 학부모 직접 선택 |
| 구독 사용량 한도 초과 | 처리량 측정 후 하루 처리 학교 수 제한, 공개 시 API 전환 |
| 개인 구독의 서비스 활용 약관 | 시범 운영 한정, 공개 전 확인 |
