# 스타일 가이드

> 2026-11-06 · 와이어프레임: [`docs/04-wireframe/index.html`](04-wireframe/index.html)
> 톤: **차분하고 믿을 수 있는 동네 선생님.** 아이 앱처럼 알록달록하지 않게, 부모가 빠르게 판단하도록.

## 1. 색

| 토큰 | 라이트 | 다크 | 용도 |
|---|---|---|---|
| `primary` | `#2F6B4F` | `#7FC4A0` | 주요 버튼, 선택된 탭, 링크 (숲 초록) |
| `onPrimary` | `#FFFFFF` | `#0F2A1E` | primary 위 글자 |
| `accent` | `#E8A13A` | `#F2BC6B` | 관심 표시 ☆, 신청 임박 강조 (연필 노랑) |
| `surface` | `#FAF8F4` | `#161816` | 화면 배경 (종이색) |
| `card` | `#FFFFFF` | `#1F221F` | 카드 |
| `text` | `#1E2420` | `#ECEFEC` | 본문 |
| `textMuted` | `#5D665F` | `#A3ABA5` | 보조 글자 |
| `border` | `#E3E0D8` | `#2E322E` | 구분선, 카드 테두리 |
| `info` | `#3B6EA8` | `#8AB4E0` | 연결 단원 꼬리표 |
| `warning` | `#B7791F` | `#E0B060` | **확인 중**, **예상** 표시 |
| `danger` | `#B3412F` | `#E8806E` | 마감 임박, 오류 |

- 색만으로 상태를 전하지 않는다. "확인 중", "예상", "마감 임박"은 **글자로도** 쓴다.
- 본문 대비 4.5:1 이상 (WCAG AA).

## 2. 글자

- 글꼴: **Pretendard** (없으면 시스템 기본).
- 크기 (sp): `title 22 / 700`, `heading 18 / 700`, `body 16 / 400`, `label 14 / 500`, `caption 13 / 400`.
- 줄 간격 1.5. 한 줄 최대 약 30자(모바일).
- 시스템 글자 크기 확대(200%)에서 잘리지 않게.

## 3. 간격·모양

- 간격 단위 4: `4, 8, 12, 16, 24, 32`. 화면 좌우 여백 16.
- 모서리: 카드 12, 버튼 10, 꼬리표 999(알약).
- 터치 영역 최소 48×48.
- 그림자 대신 1px `border`.

## 4. 컴포넌트

| 컴포넌트 | 규칙 |
|---|---|
| **프로그램 카드** | 기관명(caption) → 제목(heading) → 기간·대상(label) → 연결 단원 꼬리표(info) → 오른쪽 위 ☆. 마감 3일 이내면 `danger` "마감 임박" 꼬리표 |
| **꼬리표(Chip)** | 알약 모양, 연한 배경 + 진한 글자. 종류: 단원(info), 확인 중·예상(warning), 마감 임박(danger) |
| **가기 전에 읽어요** | 카드 안 박스, 왼쪽 📖, 책 제목 굵게 + 이유 1~2문장 |
| **오늘의 질문** | 큰 글씨(18) 질문, 아래 "힌트 보기" 접힘 버튼 |
| **주요 버튼** | primary 채움, 화면당 1개. 예: "기관 페이지에서 신청" |
| **보조 버튼** | 테두리만 |
| **하단 탭** | 홈 · 체험 · 우리 학교 · 집 실험 (4개, 아이콘 + 글자) |
| **빈 화면** | 이유 한 줄 + 다음 행동 버튼. 예: "관심 지역에 진행 중인 프로그램이 없어요 → 지역 추가" |

## 5. 글쓰기 (UX 문구)

- **해요체**, 짧게. "~하세요"보다 "~해요".
- 날짜: `11/8(토)`, 시간: `10:00`. 연도는 다른 해일 때만.
- 학년: `초3~6`, `4학년`.
- 확신 없는 정보: "확인 중이에요", "예상 진도예요".
- 오류: 무엇이 안 됐는지 + 할 수 있는 것. 예: "교과서 공지를 찾지 못했어요. 알고 계시면 알려주세요."
- 금지: 과장("최고의"), 불안 조장("놓치면 후회"), 아이 비교.

## 6. Flutter 적용

- `ThemeData(useMaterial3: true)` + `ColorScheme`에 위 토큰 매핑 (`primary`, `onPrimary`, `surface`, `error`=`danger`). `info`·`warning`·`accent`는 `ThemeExtension`으로.
- 라이트·다크 모두 시스템 설정 따름.
