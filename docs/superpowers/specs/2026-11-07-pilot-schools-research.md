# 시범 학교 홈페이지 조사 (2026-11-07)

대상: **안양 귀인초등학교**(나이스 `J10`/`7569013`, `kwiin-e.goeay.kr`)와 **화성 율목초등학교**(`J10`/`7679051`, `yulmok-e.goehs.kr`). 과천율목초는 다른 학교라 제외. 두 사이트는 같은 경기도교육청 학교 홈페이지 CMS이고, 게시판 구조·첨부 방식이 같다.

## 공통 구조 (수집기에 쓸 사실)
- 게시판 목록: `GET {사이트}/na/ntt/selectNttList.do?mi={mi}&bbsId={bbsId}&currPage={n}` (한 쪽 10건). **POST는 율목초에서 302 무한 반복** → GET만 쓴다. 제목은 `<a data-id="{nttSn}" class="nttInfoBtn">`, 등록일은 같은 행의 `YYYY.MM.DD`.
- 게시물: `selectNttInfo.do?mi={mi}&bbsId={bbsId}&nttSn={nttSn}`. 첨부는 본문 스크립트의 `DEXT5UPLOAD.AddUploadedFile(키, "파일명", "/upload/…", 크기, …)`에 있고(따옴표는 `'`·`"` 둘 다 나옴), 파일은 **`{사이트 루트}{경로}` 로 인증 없이 바로 내려받을 수 있다.** (sample: `tests/fixtures/school_*_post_attachment.html`)
- 사이트가 가끔 연결을 끊는다 → 재시도(간격을 둠)가 필요하다. 브라우저 위장은 하지 않는다.
- 게시판 이름은 학교마다 다르다. 두 학교 모두 교과서·학사일정은 **알림마당/공지사항** 게시판(귀인 `mi=6183 bbsId=2799`, 율목 `mi=7206 bbsId=3650`)에 올라온다.

## 교과서 (F7)
| | 게시물 | 첨부 | 형식 |
|---|---|---|---|
| 귀인초 | "귀인초 검인정교과서 출판사 안내" (2026.03.13, nttSn 1307880) | PDF 1쪽 | 학년별 표: `검정교과서 / 과목 / 출판사`, 5학년에 `인정교과서` 행 |
| 율목초 | "2026학년도 교과서 목록" (2026.02.05, nttSn 1232511) | XLSX (`openpyxl`로는 서식 오류로 못 읽음, 내부 XML 필요, 태그에 `x:` 접두어) | `학년 / 국정·검정·인정 / 도서명 / 저자 / 발행사`, 1~6학년 전체 |

표기 차이 (정규화 규칙에 반영해야 함):
- 출판사 뒤에 저자 이름이 붙음: `천재교육(함순애)`, `천재교과서(박만구)` → 괄호 제거.
- 철자 차이: 학교 `㈜아트앤컬쳐` ↔ 공고 `아트앤컬처`. `㈜`, `(주)`, `주식회사` 접두·접미 혼용, 하나만 `동아출판㈜` 식.
- 과목이 묶여 있음: `수학 / 수학익힘`, `과학 / 실험관찰`, `사회 / 사회과부도`(귀인), 율목은 행이 따로이고 `국어(3~4학년군)3-1가 / 3-2가` 같은 도서명에 학기가 섞임.
- 국정(국어·도덕·1~2학년 수학·바슬즐)과 인정(보건 등)이 같은 표에 섞임 → 검정만 쓴다. 단, 이 표에서 **국정 과목의 발행사**(국어=미래엔, 도덕=천재교과서, 1~2학년 수학=동아출판, 바슬즐=비상교육)를 알 수 있다.
- 검증: 두 학교 표 64건(학교×학년×과목)을 `batch/data/textbooks_2022.csv`와 대조 → 이름 정규화(위 규칙) 후 **전부 일치**.
- 같은 교육지원청 학교끼리도 출판사가 다르다: 3학년 사회가 귀인초는 비상교육, 율목초는 아이스크림미디어 → "가장 많이 쓰는 출판사"로 임시 표시하면 자주 틀린다는 뜻(임시 표시는 반드시 "확인 중" 배지).

## 학사일정·쉬는 날 (F4, S3)
- 귀인초: 게시물 "2026학년도 귀인초등학교 학사일정"의 PDF(텍스트, 표·달력). **학교장재량휴업일 5/4(월), 11/19(목, 수능일)**, 여름방학 7/25~8/17, 겨울방학 2027.1.1~2.28, 추석 연휴 9/24~27. 재량휴업일은 별도 가정통신문(4/15, 11/2)으로도 공지되고 "등교 희망 조사"를 한다.
- 율목초: 학사일정 게시물 본문이 **이미지(JPG)** 한 장(`/dext5editordata/…jpg`). 글자로 못 읽음 → 비전(이미지 읽기)이 필요. 재량휴업일 **5/1(금), 5/4(월)**, 여름방학 7/29~8/20(파란 칸), 겨울방학 2027.1.1~2.28.
- 나이스 `SchoolSchedule`: 키 없는 호출은 **처음 5건만** 준다. 키로 받은 **실제 전체 응답**(귀인 165건, 율목 157건, 2026.3~2027.2)으로 확인한 사실:
  - **재량휴업일의 구분값이 학교마다 다르다.** 율목초는 `학교장 재량휴업일`=`휴업일`(5/4), 귀인초는 `학교장재량휴업일`=**`공휴일`**(5/4, 11/19). 그래서 구분값만 보면 귀인초를 놓친다 → 이름에 `재량휴업`이 있으면 쉬는 날로 본다(파서 반영).
  - **방학은 날짜별 `휴업일` 행으로 들어 있다**(귀인 여름 24일+겨울 59일, 율목 여름 24일+겨울 59일). 이전 문서의 "방학은 날짜별 행이 없다"는 틀렸다. 재량휴업일과 섞이지 않게 **`is_vacation`으로 따로 표시**하고 `is_holiday`에서는 뺀다(`여름방학식`·`개학식`은 학교가 열리는 날이라 방학 아님). 그래서 "우리 학교 쉬는 날" 필터(`is_holiday`)는 재량휴업일만 잡는다.
  - 토요휴업일도 `휴업일`로 오므로 제외한다.
  - 학교 공지와 대조: 귀인초 5/4·11/19 일치, 율목초 5/4 일치. 율목초 이미지의 `5/1(금) 학교장재량휴업일`은 나이스에는 `노동절`(공휴일)로만 있다(쉬는 날인 것은 같음, 우리 기준으로는 공휴일이라 `is_holiday=False`). 율목초 11/19는 양쪽 모두 없음.

## 체험학습·기타 앱 관련 게시물
- **학교장허가 교외체험학습** 안내(두 학교, 2026.03·09): 나이스 학부모서비스로 **2일 전까지 신청, 종료 후 7일 이내 보고서**. 평일에 체험을 가려는 학부모에게 쓸모 있는 안내(앱 화면 문구 후보, 이 계획에서는 구현 안 함).
- **가정통신문(교육청)** 게시판(귀인 `bbsId=5252`, 율목 `bbsId=9759`)에는 지역 문화재단·교육지원청 행사 안내가 학교를 통해 전달된다(예: 안양공공예술프로젝트, 동탄 레지던시 오픈스튜디오, 안양과천 RAS 페스타). 체험 프로그램 후보 데이터지만 형식이 제각각이고 수집 대상 기관(박물관·과학관 등)이 아니라 **이 계획 범위 밖**. 이후 단계의 후보로만 기록.
- 방과후·늘봄·돌봄 계획, 재량휴업일 돌봄 운영 안내, 학생평가계획, 시간표·시정표(귀인, 본문 이미지)는 이 앱의 v1 기능과 직접 관련 없음.
